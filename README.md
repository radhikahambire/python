# Python Concepts from Scratch

This repository is a beginner-friendly, hands-on introduction to Python fundamentals. The examples are in [`main.py`](main.py) and print their results to the terminal.

## Topics covered

- **Comments:** Single-line comments (`#`) and multiline text using triple quotes.
- **Variables and naming:** Assigning values, using descriptive names, and separating words with underscores (snake_case).
- **Constants:** Python conventionally uses uppercase names for values intended to be treated as constants. The example shows that this is a convention, not an enforced restriction.
- **Type hints:** Basic annotations such as `name: str` and `number: int`.
- **Type conversion:** Converting compatible values, such as a numeric string to an integer, and checking truthiness with `bool()`.
- **Numbers and arithmetic:** Integers, readable numeric underscores, and arithmetic operators including addition, subtraction, multiplication, division, modulo, exponentiation, and floor division.
- **Operators:** Assignment, comparison, logical, identity, and membership operators.
- **Strings:** Single- and double-quoted strings, multiline strings, quotes within strings, and formatted strings (f-strings).

## Run the examples

With Python installed, run:

```bash
python main.py
```

The script prints examples and results as it runs. It is an introductory script rather than a module of reusable functions.
